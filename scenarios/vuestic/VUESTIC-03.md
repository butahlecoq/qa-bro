# VUESTIC-03 — Update Notes

Prepare an independent owned record as in VUESTIC-02 and confirm it through a fresh UI read.

1. Open Edit for the exact matching row. **edit_targets_own_user** — The identifiers and original Notes match the prepared record.
2. Replace only Notes with the supplied Updated Notes. Observe that the field contains the exact new value.
3. Click Save once, wait for the result, then reload Users and complete a search for the same full-name marker. Locate the same record.
4. Reopen Edit. **updated_notes_persisted** — Notes exactly match Updated Notes. **identity_unchanged** — Full name, Username, Email, Role, and Active remain unchanged.
5. Close Edit without further changes and verify that the table is available.

Run cleanup separately for the uniquely identified record.
